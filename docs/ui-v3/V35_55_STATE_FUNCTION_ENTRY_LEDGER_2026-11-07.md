# Softmux V3.5 — 55 状态完整功能入口与旧能力继承设计账本

> **日期：2026-11-07 · 状态：DESIGN CANDIDATE / 不替代原 V3 已批准合同**  
> Figma 可编辑设计页：<https://www.figma.com/design/5iZSy48FV1sJnGdmUf1uQc?node-id=60-2>  
> 设计对象：55 个不同任务/对象/异常状态；保留原 V3 页面及其 11 个节点，不改生产默认 UI。
>
> **决策边界**：用户明确指出原设计“11张图片还是太少了，而且实际UI有很多功能被隐藏”。本候选扩展的是功能入口覆盖，不是为满足图片数量堆叠无操作的功能陈列。原 V3 合同仍把 Batch 视为旧版可达功能；本候选提出将它恢复为常驻一级任务入口，属需要重新签核的**范围变更**。

## 1. 已完成的设计产出与不能宣称的内容

- 已在同一 Figma 文件中新建独立页面，建立 **55 个唯一编号、原生可编辑文本/图形层的界面状态**：A6、B9、C9、D8、E8、F5、G4、H6。没有用“第 11 张”规则板冒充真实界面截图。
- 核心工作台使用持续可见的任务入口：**来源、拟输出、轨道、字幕、字体、附件、批量、验证、工程**。这些是**工作区/功能入口**，并非九份业务数据库或九套独立编辑器。
- 主区域保留当前任务的真实对象集合；对象专属字段与危险操作由同一检查器承载；封装/保存/取消等重要动作保持名称。响应式页包括 1440×900、1180×820、820×1180、620×900。
- 已进一步绘制 ASS 静态渲染预览示意、ChapterUID/Tag 关系、真实表格形态的批量任务矩阵、队列进度、分层验证结果与完整空态导入区。图中的文件名、进度、字幕及错误为**设计样例，不是实际运行产物或实机证据**。
- **尚未完成**：生产代码入口一一核验、Figma 交互原型连线、相同夹具的 Figma/Chromium 对照、全部 55 态的人工视觉逐图签核、真机键盘/触控/拖放/屏幕阅读器验收。因此本设计不授权合并、默认 UI 切换或 Softmux 1.0 GA。

## 4. 基础交互合同（待批准）

1. **默认可见的入口，不是默认展开的所有参数。** 来源、拟输出、轨道、字幕、字体、附件、批量、验证、工程具备明确任务语义。所选对象的主动作直接邻近对象/检查器；高风险写入经确认与独立结果回读。
2. **来源只读；目标必须明确。** 打开 MKV 只创建来源观察。选择独立目标或空白 Matroska 目标之前不能隐式生成可执行写入计划；来源行不得借视觉一致性获得写入权限。
3. **批量恢复为一等工作区候选。** 配方 → 真实配对矩阵 → 逐项审核 → 冻结 JobPlan → 运行队列 → 保存/失败回执；保持与单工程相同来源和成果身份语义。是否进入 V3 正式 1.0 需明确批准，不能偷改原冻结合同。
4. **专业能力不可藏到“旧版”兜底。** 等长附件替换、Void 受限修改、章节标签关系、Data/Other 流、强制字体、HarfBuzz 子集、Group 字体策略等都有明确上下文入口；不支持的作用域显示禁用原因，而非静默隐藏。
5. **Generated ≠ Verified ≠ Saved；Copy ≠ 完整 EBML 保真。** 这些状态在计划、执行、验证和成品视图分别显示。失败报告必须给机器稳定 reason code 与可读解释。
6. **四种宽高状态下入口连续。** 调整窗口、旋转、移动焦点及关闭上下文页不能重新创建另一套来源 File、草稿、编辑事务或已完成任务身份。620 宽不得让主要任务依赖无限长滚动。
7. **说明不抢占主内容。** 技术解释由就地帮助与诊断进入；关键对象身份、风险、主按钮、修改差异和输出状态必须保留文本可见性。

## 5. 与原设计冲突及待审查事项

- **[BLOCKED — DESIGN AUTHORITY]** 原 Figma V3-01 的归档冻结截图为**顶部标签**，2026-11-07 当前同节点为**底部标签**。参见 PR #265 的 `V3_DESIGN_AUTHORITY_DRIFT_2026-11-07.md`。本稿新页面不修改原设计，不能以当前可变 Figma 节点擅自覆盖曾批准的视觉基线。
- **[SCOPE REVIEW]** 原批准 V3 将 Batch 作为 legacy deferred；本设计把 Batch 作为一级任务，需用户/产品签核。
- **[CAPABILITY REVIEW]** 原始 44 项旧功能仍需基于最新 `main` 源码逐个确认在 V3 下的入口、能否完成真实用户任务；受限写入方案不可因展示控件被认定已经通用化。
- **[VISUAL REVIEW]** 本页状态是**可编辑 UI 设计候选**，大部分仍为统一架构的对象列表+检查器表现，不是 55 个已获批的高保真、可实际点击运行的产品界面。
- **[FIELD REVIEW]** 平板真机、软键盘、OS 拖放、读屏器与大型真实媒体端到端测试未执行。
