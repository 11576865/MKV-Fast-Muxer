# Softmux V3 — 默认界面切换与回退记录（2026-11-07）

## 授权和范围

用户明确要求“做成正式界面”，因此本轮执行的是**产品首页默认呈现 V3 Object-first 工作台**，不是仅保留 `?ui=v3` 的可选预览。该授权允许改变默认 UI 路由，但**不表示**所有 Figma 状态已完成一致性签核、实体设备通过或软封 1.0 Release Gate 已通过。它也**不授权**放宽媒体写入、文件身份、字体闭包或来源保真门槛。

产品实现仍复用原有 10.14 工作台和同一 FFmpeg.wasm/输出审计；V3 是实际 DOM 上的界面编排，不复制一套媒体执行器。

## 路由与回退矩阵

| URL 模式 | 呈现界面 | 媒体写入权限 |
| --- | --- | --- |
| 普通网站根路径 `/` | **V3 默认正式 UI** | 必须先显式确认真实目标 File 或新建空目标，不因打开来源而授权 |
| `?ui=v3` | 与根路径**完全相同的 V3** | 同上，兼容已有评审/测试链接 |
| `?ui=workbench` | 之前默认的 0.1014 系列对象工作台（10.14 DOM 内部命名） | 保持原有工作台独立可执行边界 |
| `?ui=legacy` | 更早的原始诊断界面 | 保持原有诊断/回归能力 |
| 未知 `?ui=` 值 | V3 默认 | 不降级到无目标约束的旧模式 |

V3 右上角原有“保留的旧工具”菜单新增真实链接“切换至上一版工作台”指向 `?ui=workbench`，供用户主动回退。切换路由会重新加载网页；浏览器 File 对象及本次未下载的 MKV/报告不会跨页面转移，回退前应先保存输出及工程草稿。

## 实施注意事项

1. `src/ui-mode.js` 提供纯路由解析，`src/main.js` 的 `v3Pilot` 内部布尔值依旧**在默认首页为 true**：真实输出权限检查、明确目标确认、来源只读、空白 MKV writer 权限由同一个值约束。不能仅修改 `mountSoftmuxV3Surface()` 调用条件而遗漏执行权限。
2. 保留 `?ui=legacy` 的纯诊断视图，并通过新 `?ui=workbench` 精确恢复之前的生产工作台；不得由新增路线隐式复制编辑器或修改选中的 File。
3. 旧媒体回归 `tests/e2e/browser-mux.e2e.mjs` 显式使用 `?ui=legacy`/ `?ui=workbench` 测试原两种保留界面，不再假设普通根路径等于旧工作台。
4. V3 源载入真实点击/拖放测试直接在普通根路径执行；独立 `tests/e2e/v3-default-route.e2e.mjs` 检查根路径的来源只读、无目标禁写、旧版链接真实点击、`?ui=v3` 兼容、`?ui=legacy` 原界面和未知模式的安全默认。以上由 V3 Chromium CI 精确提交运行。
5. 新版默认标记只代表**UI 入口**，不会把现有 1.0 的 `UNASSESSED`/未通过条目改为 PASS。跨设备触控/软键盘/屏幕阅读器/系统级拖放、未匹配 fixture 的视觉差异仍由 [Issue #256](https://github.com/11576865/MKV-Fast-Muxer/issues/256) 追踪。

## CI、合并和实际部署边界

**完成顺序：** 提交候选 → Node/unit、V3 专项真实 Chromium、legacy+10.14 完整 Browser E2E、独立新建 Matroska、S12（如触发）及 Pages 精确 HEAD 审核 → 通过后合并 `main` → 核对主干构建和线上首页实际 `.sfv3` → 才宣称“网站默认 UI 已生效”。

代码已在 Draft PR #262 的工作分支中提交，且早前分支的全部绿色检查**不能替代切换后的精确 SHA CI**。任何尚未结束的测试须保留为 Pending，不能自行填写 PASS；未合并之前 GitHub Pages 的 PR 检查也不能视为默认首页已上线。

## 回滚

如果新 UI 阻断关键任务：

- **即时用户回退：** 使用 V3 菜单“切换至上一版工作台”（`?ui=workbench`）；诊断需用 `?ui=legacy`。重新选择本地来源和输出路径。
- **产品回滚：** 在 GitHub 上撤销默认路由切换的提交/合并，并由精确主干构建重新部署；保留 V3 直达入口作定位，不动媒体执行器。
- **必须保留：** 原本的完整来源文件、成品与审计报告的身份校验、显式 File 许可、最终 FFprobe 与异常时禁止虚报 PASS。
