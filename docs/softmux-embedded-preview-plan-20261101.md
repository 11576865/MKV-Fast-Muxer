# 来源 ASS/字体按需预览

沿用已授权的 1.0 工作台集成目标及现有 FFmpeg/libass 预览，不新增可写领域或独立资源导入。

- 只给精确当前 File 的已扫描 ASS/SSA stream 添加预览下拉选项；预览包含已排除输出的来源轨道。
- WORKERFS 挂载当前来源，按真实 stream index 提取临时 ASS，保留时间轴；输出达到 8 MiB 则拒绝，不展示截断字幕。
- 复用 seek-based Matroska 附件读取器，按内容头发现字体，解析后载入临时字体目录；使用生成名称，最多32项/每项8 MiB/合计32 MiB。损坏或超预算字体明确失败。
- 来源预览保持来源 ASS 和内封字体，不继承外部字体强制改写；不改变来源轨道、附件及外部资源的输出选择。
- 来源/预览代次变化使异步结果失效；清理挂载、ASS、字体及帧，保持既有外部 ASS 预览。
- 验证精确来源绑定、预算/损坏/过期负例；真实浏览器只导入 MKV，使用独特字体名称证明内封字体被选择，核对预览及之后实际输出，验证切换来源清理。

这次能力限于来源 ASS/SSA 静态帧，不等于全部字幕预览或整个 S03/1.0 验收完成。
