# 批量纯容器只读检查

原始决议 B-017 明确为“批量只检查容器而不重封装”，不改变原批量字幕匹配/18-of-20确认/封装任务分母。

- 沿用现有批量素材选择，新增显式“仅检查容器”操作；没有字幕也可运行，每批最多100项。
- 精确 File 列表冻结，顺序检查，失败继续；停止时丢弃当前未提交观察并标记剩余未检查，已完成报告保留。选择变更中断过期运行。
- 复用 WORKERFS/FFprobe、只读 Matroska 附件及风险观察，不调用 MKV writer，不应用 writer 布局/文件大小准入限制，不改变单工程领域或旧批次成品。
- 流/附件/章节/标签是结构观察；不宣称解码、全部 EBML 保真、附件 payload 哈希或写入许可。缺少轨道/仅独立附件结构等结果标为部分观察，不能虚报完整媒体检查。
- 独立逐项和汇总 JSON 下载，完成检查、生成报告、实际持久化保持不同语义；新检查仅释放旧检查的 URL，不触碰封装成品。
- 验证无字幕多来源、有效/坏来源混合、错误后继续、取消/过期、无效空结果、单工程和旧封装结果隔离、来源字节不变、独立原生元数据对照。
