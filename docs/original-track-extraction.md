# 原音频、字幕轨道独立提取

导入 MKV，待实际轨道扫描完成后，在来源树选中音频或字幕，在对象检查器使用“提取此原轨道”。无需先执行新的封装，也可在“保留全部”或该轨道被排除输出时读取原内容。

| 原轨道 | 单轨容器 | 原生文件 |
| --- | --- | --- |
| AAC | MKA | AAC（ADTS） |
| FLAC | MKA | FLAC |
| MP3 | MKA | MP3 |
| AC3 / EAC3 | MKA | AC3 / EAC3 |
| ASS / SSA | MKS | ASS |
| SubRip | MKS | SRT |
| PGS | MKS | SUP |
| VobSub | MKS | 暂不生成 IDX/SUB 双文件 |

单轨容器采用 Stream Copy 和原时间轴保护。原生文件可能重建传输头或重新建立时基，例如 AAC/ADTS 不能保存原容器的绝对起始时间；不将这些格式当作完整容器保真副本。

提取读取原文件的实际轨道索引与原始标题/语言，不应用尚未封装的属性修改。原文件、当前编辑历史/封装计划和已有封装成品保持独立。文件或扫描轨道身份改变后，旧提取链接失效。可取消并重新提取；仅有音频的 MKA 也可直接作为来源。

提取结果不包含字体附件、章节、全局标签、轨道/附件 UID 关系。ASS 显示效果可能需要另行提取原字体。浏览器报告只证明单轨结构、编码及参数/适用元数据回读和输出 SHA-256，不将这些检查冒充逐包内容验证。

本轮独立原生验证覆盖9类编码的14份导出、取消后恢复和无视频来源。核对包载荷/数量、MKA/MKS 时间戳及编码私有数据；PGS 按显示集规范化，AAC 原生输出按 ADTS 传输头规范化后比较载荷。证据仅针对具名夹具，不保证任意播放器或目标设备表现。
